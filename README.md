# 🛒 Online Shop – React App

Ein moderner Online-Shop, entwickelt mit React, der es ermöglicht, Produkte zu suchen, zu filtern und zu verwalten.

## ✨ Features

- **Produktsuche** – Produkte anhand ihres Namens suchen.
- **Kategorie-Filter** – Produkte nach verschiedenen Kategorien filtern.
- **Preisfilter** – Produkte anhand eines Mindest- und Höchstpreises filtern.
- **Warenkorb** – Produkte zum Warenkorb hinzufügen.
- **Favoriten** – Produkte zu einer Favoritenliste hinzufügen.
- **Navigation** – Zwischen verschiedenen Seiten mit React Router navigieren.

## 🛠️ Technologien

- React
- JavaScript
- CSS
- HTML
- React Router

## 🚀 Ziel des Projekts

Das Projekt dient dazu, praktische Erfahrungen mit React, State-Management, dynamischen Produktfiltern, Suchfunktionen und clientseitiger Navigation mit React Router zu sammeln.
